# Антон Афанасьев

**QA Engineer / AI Explorer**

Персональное портфолио о тестировании, качестве продуктов и исследовании AI. Здесь собраны профессиональные направления, инструменты, проекты и увлечения.

**[Открыть портфолио →](https://anton-afanaciev.github.io/anton-portfolio/)**

## Возможности

- Одна страница с навигацией по разделам.
- Карточки QA- и AI-инструментов с раскрываемыми описаниями.
- Фильтры проектов по категориям.
- Фотокарточки увлечений и ссылки для связи.
- Светлая и тёмная темы с сохранением выбора.
- Адаптивный интерфейс, управление с клавиатуры и уменьшение анимаций.

## Технологии

React · TypeScript · Vite · CSS · Vitest · Playwright

## Локальный запуск

Нужны Node.js 22.12+ или 24 LTS и npm.

```bash
npm ci
npm run dev
```

Сайт откроется по адресу http://127.0.0.1:5173/anton-portfolio/.
